## Analisis jangkauan (reachable dari jaringan?)

Diperiksa di container berjalan (read-only: `ps`, `ss -tlnp`, `/proc/<pid>/maps`, `apt-cache rdepends --installed`,
`doveconf -n`, `redis.conf`). Proses yang berjalan: supervisord, postfix (master, smtpd, postscreen, qmgr, pickup, tlsmgr),
dovecot (imap, auth, anvil, log, config), rspamd ×5, redis-server, rsyslogd, cron, check-for-changes. **Tidak ada** proses
perl, opendkim, clamav, named/unbound.

| Paket rentan | Dipakai oleh | Jangkauan | Penilaian |
|---|---|---|---|
| perl (CRIT ×3, fixable) | skrip utilitas DMS/`setup` (dijalankan admin), bukan daemon | tidak ada input jaringan | **tidak terjangkau** |
| libunbound8 (CRIT ×3) + libevent (HIGH ×6) | hanya `opendkim` (`rdepends`); `ENABLE_OPENDKIM=0` | proses tidak berjalan | **tidak terjangkau** |

dan bug parser libxml2/glib yang dimuat rspamd (tidak bisa dikesampingkan, tidak ada eksploit publik yang diketahui per
2026-09-25).

## Kontrol kompensasi

1. **Hardening B18 (bagian dari keputusan ini):** acme.json penuh tidak lagi di-mount; container hanya menerima
   cert/key `mail.bimacreative.tech` (`mail/scripts/tls-export.py`, role `mail_tls_export`, `docs/03-operations/mail.md`
   §TLS). Kompromi container tidak lagi membocorkan kunci privat hostname lain (cp, auth, Odoo tenant, dll).
2. Layanan non-esensial OFF: ManageSieve, POP3, OpenDKIM, OpenDMARC, policyd-spf, ClamAV, Amavis, SpamAssassin,
   fail2ban DMS, update check. 143 tidak di-publish.
3. `cap_drop: [ALL]` + 7 cap minimal, `no-new-privileges`, `mem_limit 1024m` / `cpus 0.75` (DoS dibatasi ke container ini).
4. CrowdSec (postfix + dovecot collections + skenario lokal SASL BF) + firewall bouncer host; ufw hanya 25/465/587/993.
5. Rspamd controller & Redis tidak di-publish; network `mail` tanpa anggota lain.
6. Healthcheck `dms-healthcheck` + monitor Kuma SMTP/IMAPS + `infra-healthcheck` (alert email) → DoS terdeteksi.
7. Backup harian maildir/config (restic `files`).

## Tindak lanjut & kriteria keluar

1. **Mingguan** (paling lambat setiap Kamis): cek Docker Hub tags + GitHub releases DMS. Perintah:
   `curl -fsS 'https://hub.docker.com/v2/repositories/mailserver/docker-mailserver/tags?page_size=10&ordering=last_updated'`
   dan `curl -fsS https://api.github.com/repos/docker-mailserver/docker-mailserver/releases?per_page=3`.
2. **Keluar (acceptance selesai):** rilis resmi **`16.0.2` atau `16.1.0`** (atau lebih baru) tersedia → baca CHANGELOG
   (breaking change) → pin tag + digest index → Trivy ulang (metode di atas) → bila CRITICAL fixable = 0 atau semuanya
   tidak terjangkau: upgrade (recreate ±1 menit, `mail.md` §Start) dan tutup dokumen ini.
3. **Review 2026-10-09:** bila belum ada rilis → Trivy ulang + cek eksploit publik untuk dovecot/libxml2/glib; Lead memutuskan
   perpanjangan (maks. 2 minggu per perpanjangan) atau alternatif (mis. build image sendiri lewat ADR baru).
4. **Gugur segera** (eskalasi ke Lead hari yang sama) bila: eksploit publik untuk paket yang dimuat daemon terekspos
   (postfix, dovecot, rspamd + glib/libxml2/pcre2, openssl), atau DMS menerbitkan security advisory untuk 16.0.x.
5. Jangan mengaktifkan ManageSieve, OAuth2/MySQL Dovecot, OpenDKIM, atau ClamAV selama acceptance berlaku (mengubah
   analisis jangkauan di atas).
