## Bukti PoC isolasi (container sysbox dengan flag identik supervisor)
- `Runtime=sysbox-runc Privileged=false NanoCpus=2000000000 Memory=4294967296 MemorySwap=4294967296 PidsLimit=4096
  CpuShares=256 OomScoreAdj=800 SecurityOpt=[no-new-privileges:true] Ports=map[] Mounts=/srv/ci/cache:/cache /srv/ci/docker:/var/lib/docker`;
  `cpu.weight`=10; `BlkioDeviceWriteBps=[/dev/loop0:60MB /dev/sda:60MB]`.
- Di dalam: `uid_map 0 231072 65536`; `NoNewPrivs: 1`; sebagai uid 1001: `sudo -n true` → ditolak (NNP); `/opt/infra`, `/opt/src`
  tidak ada; socket = dockerd **dalam** (`docker info` Name=`ci-runner`, 29.7.2, storage driver-type `io.containerd.snapshotter.v1`).
- Host: `ps` → `dockerd` dalam berjalan sebagai **uid host 231072** (bukan 0).
- Kompatibilitas workflow: `docker run -p 127.0.0.1:5432:5432 postgres` → `127.0.0.1:5432` terjangkau dari langkah; `docker run -v $PWD:/src`
  OK; `docker build` OK; buildx 0.36.1; egress inner container OK; `nodev`/`nosuid` pada `/srv/ci` tidak mengganggu overlayfs dalam.
- ID-mapped mount: file dibuat uid 1001 di container = uid 1001 di host; `/var/lib/docker` root↔root.
- Entrypoint dengan JIT palsu: JIT terbaca dari env `ACTIONS_RUNNER_INPUT_JITCONFIG` (log runner `Env arg 'jitconfig': '***'`, dihapus dari env
  listener oleh runner), dockerd dalam start, runner uid 1001, cleanup post-run, container keluar.
